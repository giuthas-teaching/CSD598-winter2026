\frame{\frametitle{Dispersion and shape}

\begin{columns}
  \begin{column}{.35\textwidth}
    Dispersion
    \begin{itemize}
      \item Range, quartiles: easy to calculate on samples
      \item Standard deviation (SD), variance: most used
      \item Average absolute deviation: more robust than SD
    \end{itemize}
    \vspace{.5cm}

    \begin{itemize}
      \item Skewness: which way does the distribution lean?

\frame{\frametitle{Choosing a good graph}
  \begin{itemize}
    \item The following need to serve a purpose:
    \begin{itemize}
      \item Graph type
      \item Colour
      \item Fancy effects
    \end{itemize}
    \item Generally, the purpose should be conveying information.
    \item Secondarily, it can be to aid with conveying of information. For
    example, by making the graph look nice and actually be read as a result.
  \end{itemize}
}


\frame{\frametitle{Designing a good graph}
  \begin{itemize}
    \item Figure out what you are wanting to say and how the data shows that.
    \item Printed versions may be very different from what is shown on a screen.
    \item Mind accessibility:
    \begin{itemize}
      \item Everybody does not see colour in the same way.
      \item Everybody does not {\em see}.
    \end{itemize}
  \end{itemize}
}


\frame{\frametitle{Resources for choosing a graph}
  \begin{itemize}
    \item \url{https://royal-statistical-society.github.io/datavisguide/}\\
    Good, approachable guide to data visualisation.
    \item \url{https://www.data-to-viz.com/}\\
    Actual recommendations with actual code (R, Python, D3.js, React) to get
    going. 
    \item \url{https://r-graph-gallery.com/}\\
    Neat gallery for getting to know different graph types. (Not exhaustive though.)
    \item Doesn't take much to find more. Please post any good ones you like in
    Canvas.
    \item My own favourite tool is the pairs plot in R. So we'll have a look at
    an example of that.
  \end{itemize}
}
